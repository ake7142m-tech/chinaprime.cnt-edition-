# chinaprime.cnt-edition-ขอบเขตงาน UI/Design System - Create component library & Tailwind config
📱 Frontend Structure - Set up app1. ปรับ UX/UI ทั้งเว็บไซต์
ทำฟอนต์ สี ปุ่ม การ์ด รูปภาพ และเอฟเฟกต์ให้เป็นมาตรฐานเดียวกัน
ปรับดีไซน์ให้ทันสมัย พรีเมียม และอ่านง่าย
รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์
ใช้ภาษาและชื่อเมนูให้เป็นแนวทางเดียวกันทุกหน้า
2. ระบบหลังบ้าน
เพิ่ม ลบ แก้ไข และจัดเรียงโปรแกรมทัวร์
จัดการราคา รอบเดินทาง ที่นั่ง รูปภาพ และไฟล์โปรแกรม
เพิ่ม ลบ แก้ไขข่าว บทความ รีวิว และแบนเนอร์
แก้ไขข้อมูลหน้าเว็บได้เองโดยไม่ต้องแก้โค้ด
3. ระบบจองและสมาชิก
สมัครสมาชิกและเข้าสู่ระบบ
เลือกทัวร์ รอบเดินทาง และจำนวนผู้เดินทาง
จองทัวร์ แนบหลักฐานชำระเงิน และตรวจสอบสถานะ
สมาชิกดูประวัติการจองและดาวน์โหลดเอกสารได้
4. Live Chat
แชตสอบถามข้อมูลเบื้องต้นและรับลูกค้า
เชื่อมต่อ LINE หรือ Messenger
เก็บชื่อ เบอร์โทร และโปรแกรมที่ลูกค้าสนใจ
5. Dashboard สถิติ
จำนวนผู้เข้าชมรายวัน รายเดือน และทั้งหมด
ดูหน้าหรือทัวร์ที่ได้รับความนิยม
ดูแหล่งที่มาจาก Google, Facebook, TikTok และ LINE
เก็บจำนวนการคลิกปุ่มจอง แชต โทร และดาวน์โหลดโปรแกรม
เชื่อม Google Analytics และ Google Search Console
6. SEO
หลังบ้านแก้ไข SEO Title, Description, URL และภาพแชร์ได้
เพิ่ม Sitemap, Canonical, Schema และ Breadcrumb
ปรับชื่อและคำอธิบายแต่ละหน้าให้ตรงกับเนื้อหา
ตรวจสอบข้อมูลและปีเดินทางให้เป็นปัจจุบัน
7. ความเร็วและความปลอดภัย
ลดขนาดรูปภาพและเพิ่มความเร็วในการโหลด
ติดตั้ง Cookie Consent ตาม PDPA
ป้องกัน Spam และเพิ่มระบบสำรองข้อมูล
ตรวจสอบปุ่ม ลิงก์ ฟอร์ม และระบบต่าง ๆ ก่อนเปิดใช้งานจริง
ข้อที่1 ความคาดหวังของผุ้ใช้งาน  คือ 1 หวังว่าจะไม่ไปแก้ไขโครงสร้างเดิมเช่นสี หรือต่างๆท2 เราจะต้องทำให้ครบทุกขั้นตอนและตรวจสอบความสอดคล้องของระบบ   ไม่ข้ามขั้นตอน ไม่ตัเขั้นตอนออก ๆม่คิดเข้ามาเพิ่ม ไม่นอกกรอบ
